¡Hola developer 👋🏻! En este repo encontrarás una pequeña app Node.js que muestra las ventajas de usar [Docker Hardened Images](https://docs.docker.com/dhi/how-to/use/). La propia app sirve como ejemplo: el mismo servidor se puede ejecutar con una imagen regular o con una imagen hardened para comprobar las diferencias en runtime.
